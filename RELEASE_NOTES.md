# 2.2.3

- **In-order chains remember how far you got.** Dawn Waker and the other
  secrets that must be done in order now save your furthest step per
  character, so a step stays done after the item it relied on is used up or
  thrown away. Thanks again to Steelrat333.
- **CLUCK! ticks its first step** as soon as you have the quest, not only once
  it is handed in.
- **Alcaz Operative Insignia:** the State Secrets step has a map pin for each
  faction (Stormwind for Alliance, Booty Bay for Horde).
- **Cozy Sleeping Bag:** climbing tips for Thoradin's Wall on the Eagle's Fist
  step.
- **Scarlet Banner:** level 33+ for the Scarlet Monastery Library, per the
  updated Wowhead guide.
- **Night Watchman's Torch:** ten map pins for the slain guard, up from six,
  per the 26 November guide.
- **Help automate WoW: Forever:** the README explains how to find the hidden
  quest IDs behind a step with QuestsChanged and report them, so more steps
  can tick off on their own.
